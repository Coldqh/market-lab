# Лаборатория рынка

Учебный веб-тренажёр фьючерсной торговли, расчёта прибыли/убытка, маржинального обеспечения и влияния экономических событий. Интерфейс полностью на русском языке. Все деньги и котировки **виртуальные**.

## Запуск

Откройте `index.html` в браузере. Приложение написано на HTML, CSS и JavaScript без сборки, сервера и сторонних библиотек.

## Разделы

- **Торговля:** три синтетических фьючерса (MES, CL, GC), свечной график, шаги по 15 минут, покупка и продажа, обеспечение, комиссии, текущая прибыль, закрытие сделок, автоматическая ликвидация при нарушении учебного лимита.
- **Обучение:** шесть кратких объяснений и шесть заданий с проверкой ответа и разбором.
- **История:** журнал открытия/закрытия сделок, экономических событий, статистика закрытых сделок и экспорт CSV.

Можно применить четыре учебных макроэкономических сценария: повышение ставки, сокращение добычи нефти, замедление инфляции, банковский кризис. Влияние этих сценариев задано заранее и не является прогнозом. Состояние сохраняется локально через `localStorage`.

## Обоснование продукта

**Проблема:** начинающие пользователи знают определения фьючерса, маржи и короткой позиции, но испытывают трудности с практическими расчётами и анализом рисков.

**Цель:** дать безопасную среду, в которой можно открыть виртуальную позицию, увидеть финансовый результат и отработать базовые понятия.

**Аудитория:** студенты экономических дисциплин, начинающие изучать финансовые рынки, преподаватели при демонстрации принципов биржевой торговли.

## Реализация и ограничения

- Сайт адаптирован для настольных и мобильных браузеров.
- Для работы не нужны учётная запись, подключение к бирже или внешние API.
- Номинальная стоимость позиции = цена × множитель × число контрактов.
- В учебной модели начальное обеспечение = 10% номинальной стоимости; принудительное закрытие происходит, когда стоимость счёта становится меньше 75% занятого обеспечения. Это **не** правила конкретной биржи.
- Текущий результат = (текущая цена − цена открытия) × множитель × контракты × направление, где покупка +1, продажа −1.
- Комиссии вычитаются при открытии и закрытии. На одном активе одновременно может быть одна позиция.
- Рыночные цены, сценарии, свечи и объёмы не поступают с настоящих бирж. Реальные финансовые операции невозможны.
