# MARKET / LAB — учебный симулятор фьючерсов

Рабочий статический сайт на HTML, CSS и JavaScript. Не требует сервера или настоящего брокерского счёта.

## Дизайн

Взята **исходная компоновка терминала 2010-х**: та же тёмно-серая палитра, тонкие линии, прямые углы, шрифты и сетка из трёх рабочих областей с нижней таблицей. Мы изменили содержимое старых панелей, а не тему оформления.

## Что умеет

- Динамический свечной график с 3 учебными фьючерсами: MNQ (индекс Nasdaq 100), CL (нефть WTI), GC (золото).
- Покупка и продажа 1–20 контрактов с немедленным расчётом номинала, обеспечения и комиссии.
- Живые виртуальные P&L, баланс, свободные средства, закрытие позиции и упрощённое принудительное закрытие при недостатке средств.
- Симуляция движения котировок: +1/+10 свечей либо воспроизведение.
- 5 макроэкономических сценариев с объяснением гипотетической реакции 3 активов.
- 6 учебных тем, 6 практических задач с проверкой и объяснением.
- История сделок и событий, статистика, сохранение состояния браузером, выгрузка журнала CSV.

## Что убрали как не относящееся к цели MVP

Биржевой стакан со случайными объёмами, Time & Sales с псевдосделками, лимитные и OCO-заявки, фиктивные шаблоны ордеров, рисование на графике, настройки раскладки, несколько дублей BUY/SELL, избранное и экспорт изображения графика. Их панели переиспользованы под учебные сценарии и объяснение расчётов.

## Как запустить

Откройте `index.html` в современном браузере или разместите файлы на любом статическом хостинге, включая GitHub Pages. Для приложения не требуются сторонние библиотеки и API.

### Важные ограничения модели

- Рыночные данные **синтетические**. Сценарии применяют фиксированные процентные изменения. Они не отражают фактическое поведение цен.
- Начальная маржа моделируется постоянной процентной ставкой для каждого инструмента, поддерживающая — 75% от неё. Это **учебные упрощения**, не правила CME.
- Комиссия 0,0025% от номинала каждой стороны, без отдельного моделирования спреда, проскальзывания и финансирования.
- Симулятор ведёт не более одной открытой позиции на один инструмент одновременно. Итоговый результат включает комиссии открытия и закрытия.
- Нет реальных брокерских операций, рыночного стакана, поставки актива, расчётов вариационной маржи и даты экспирации.
- Это образовательный продукт, **не инвестиционная рекомендация**.

## Сохранение прогресса

Версия сохраняет данные под ключом `marketlab-education-workstation-v4` в `localStorage` браузера. Данные старых прототипов не удаляются, поэтому возможен возврат к старой версии без потери сохранения в ней.

## Проверяемые сценарии

1. При загрузке отображаются график и 50 000 $ виртуального капитала.
2. При покупке и изменении цены обновляется нереализованный результат.
3. При закрытии позиции списывается комиссия и создаётся запись о сделке.
4. При недостаточном обеспечении открыть сделку нельзя.
5. Сценарий нефти меняет учебные цены и записывается в журнал.
6. После правильного ответа счётчик лаборатории растёт, объяснение отображается.
7. Перезагрузка страницы сохраняет текущую учебную сессию.
8. Новая сессия сбрасывает прогресс только после подтверждения.

## Финансовое ядро 1.1

Цены теперь округляются к тикам, прибыль и комиссии рассчитываются в целых центах, денежные движения записываются в независимый журнал. Старый ключ localStorage версии v4 сохраняется: его данные переносятся в v5 без удаления исходника. При миграции старая цена входа может быть округлена до биржевого тика. Проверка: npm run check. Стиль и CSS не менялись.
