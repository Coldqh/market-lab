# MARKET / LAB — Futures Workstation

MARKET / LAB 1.2 — учебный симулятор фьючерсного рынка с интерфейсом в эстетике настольных торговых терминалов 2010-х годов.

## Возможности

- Плотная рабочая станция **Chart / Order / DOM / Time & Sales / Blotter**: тёмно-серая палитра, прямые углы, панели и таблицы.
- Свечной и линейный график на Canvas, таймфреймы, SMA(12), сохранение графика PNG, ручное и автоматическое движение рынка.
- Девять синтетических контрактов: MNQ, ES, NQ, RTY, YM, CL, NG, GC, SI.
- Рыночные и лимитные заявки; LONG/SHORT, P&L, комиссия, маржа, закрытие и разворот позиции, отмена заявок, условное исполнение лимитных ордеров при касании ценой.
- Учебные **DOM ladder / market depth** и **Time & Sales** — полностью моделируемые объёмы и сделки, не реальные биржевые данные.
- Нижние вкладки **Accounts, Positions, Orders, Trades, Events, Notes**.
- Макросценарии и лабораторные задачи, история операций, статистика, CSV-экспорт.
- Сохранение сессии в localStorage; адаптация под узкие экраны.

## Запуск

Откройте `index.html` в браузере либо запустите любой статический веб-сервер. Сборка и зависимости не нужны.

## GitHub Pages

`.github/workflows/deploy.yml` автоматически публикует сайт из `main` в GitHub Pages.

## Ограничения

Стартовый баланс: **$50,000 виртуальных долларов**. Все котировки, ликвидность стакана и события синтетические. Маржинальная модель упрощена; максимум одна открытая позиция на один инструмент. Предустановленные OCO/bracket-ордеры и инструменты рисования пока не реализованы. Не используется настоящая биржа или брокер; сайт не предназначен для реальной торговли.
